Spotify Clone

About the Project

Building this project was not easy. I faced many errors and challenges during development, but I didn't stop. I kept trying, fixing bugs, learning new things, and improving my code.

After all those challenges, I finally built my own Spotify-inspired music player using HTML, CSS, and JavaScript.

This project represents my learning, practice, and the effort I put into becoming a better developer.

Live Demo

You can check out my project here:

"View My Spotify Clone" (https://spotify-sigma-web-dev.vercel.app/)

I'd love to know what you think about it.

Features

- Responsive design for desktop and mobile
- Play and Pause music
- Next and Previous song controls
- Interactive music seekbar
- Local songs library
- SVG icons
- Interactive music player built with JavaScript

Technologies Used

- HTML5
- CSS3
- JavaScript
